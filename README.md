# DOHA-DC01 – Enterprise Data Center Network Build & Troubleshooting Lab

> A simulated data center network built in Cisco Packet Tracer, hardened like production, then deliberately broken in **8 incident scenarios** and restored using a documented, bottom-up troubleshooting runbook.

![Topology](docs/images/topology.png)

## What this demonstrates
| Skill | Evidence in this repo |
|---|---|
| Network segmentation (VLANs) | Servers, clients, management, parking and native VLANs: `configs/` |
| Redundancy | LACP EtherChannel between switches; failure test in [INC-07](incident-reports/INC-07.md) |
| Inter-VLAN routing + DHCP | Router-on-a-stick: `configs/R1.txt` |
| Hardening | SSH-only, port-security, BPDU guard, unused ports shut, native VLAN ≠ 1 |
| Monitoring | Central Syslog + NTP + DNS on SRV-WEB01 |
| Incident management | 8 [incident reports](incident-reports/) with root cause and prevention |
| Physical-layer discipline | [Rack elevation & cable schedule](images/rack-elevation.png) with label standard |

## Design

## Incident scenarios
| INC | Fault | Layer | Key command | Impact |
|---|---|---|---|---|
| [01](incident-reports/INC-01.md) | Port administratively down | L1/L2 | `show interfaces status` | Server down |
| [02](incident-reports/INC-02.md) | Cable patched into wrong port | L1 | `show interfaces status` + label check | Server down |
| [03](incident-reports/INC-03.md) | Wrong access VLAN | L2 | `show vlan brief` | User down + security risk |
| [04](incident-reports/INC-04.md) | Wrong default gateway | L3 | `ipconfig`, `tracert` | Cross-subnet down |
| [05](incident-reports/INC-05.md) | VLAN pruned from trunk | L2 | `show interfaces trunk` | Server isolated |
| [06](incident-reports/INC-06.md) | Port-security violation | L2/Security | `show port-security interface` | Port err-disabled |
| [07](incident-reports/INC-07.md) | EtherChannel member failure | L1 | `show etherchannel summary` | **None, redundancy lost** |
| [08](incident-reports/INC-08.md) | Wrong 802.1Q tag on router | L2/L3 | `show run int g0/0.20` | All clients down |

## Verification
All baseline tests in [verification/test-matrix.md](verification/test-matrix.md) pass: inter-VLAN routing, cross-switch L2, SSH accepted / Telnet refused, DNS resolution, EtherChannel and STP root state.
